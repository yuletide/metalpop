# MetalPop Frontend

Next.js application for visualizing global metal band distribution data.

## Features

- **Interactive Map**: Mapbox GL-powered visualization of metal band density
- **Genre Filtering**: Filter data by metal genre (when data layers are available)
- **Region Details**: Click on regions to view detailed statistics including:
  - Region name and country
  - Total number of bands
  - Bands per 100,000 people
  - Population data
  - Area
- **Responsive Design**: Works on desktop and mobile devices
- **Dark Mode**: Supports light and dark themes

## Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Configure Mapbox token:**
   
   Copy the example environment file:
   ```bash
   cp .env.local.example .env.local
   ```
   
   Edit `.env.local` and add your Mapbox access token:
   ```
   NEXT_PUBLIC_MAPBOX_TOKEN=your_mapbox_token_here
   ```
   
   You can get a free Mapbox token at: https://account.mapbox.com/

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Data Integration

The frontend is designed to work with the data processing pipeline in the parent directory. The map uses Mapbox tilesets generated by the `make all_bands` workflow.

### Using Your Own Tileset

If you've processed your own data:

1. Update the `NEXT_PUBLIC_MAPBOX_USER` in `.env.local` to your Mapbox username
2. Ensure your tileset is named `ne_bands_percapita` or update the component

### API Endpoints

- `GET /api/data?genre=<genre>` - Get data for a specific genre
- `GET /api/genres` - Get available genres

Currently, these are placeholder endpoints ready for database integration.
